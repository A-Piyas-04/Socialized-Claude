# Emoji palette

This file supports the visual operation in `SKILL.md`. It is the full set of
navigation icons to choose from, grouped by meaning, plus the closed status
legend. Every icon here is a single code point from Emoji 11 or earlier, with no
skin tones, flags, or joined sequences, so it renders on current Windows, macOS,
Linux, iOS, Android, and claude.ai.

## 1. How to use an icon

- Pick the icon whose meaning matches what it labels. A 🔒 opens a section about
  access control, not a section about speed.
- Put a navigation icon at the start of a heading, a callout, or a bullet label,
  followed by a space and the words. The words carry the meaning; the icon helps
  the eye find it.
- Keep icons out of code, JSON, file paths, commands, and identifiers.
- Use navigation icons in teaching and long answers only. A formal reply, a
  casual exchange, or a one-line answer gets none.
- Use one icon per meaning across the whole answer. If 🧪 marks testing in one
  section, it marks testing in every section.
- Delete any icon that does not help the reader find something. An answer with
  more icons than headings, callouts and list labels has drifted into decoration.

## 2. Status layer (closed)

These six mark a status, not a topic. Use them only at the start of a list item
or table cell, use at least two distinct ones in that list or table, and name
what they mean in the caption. Keep them off headings.

| Icon | Use it for |
| --- | --- |
| ✅ | works, passes, allowed |
| ❌ | broken, fails, not allowed |
| ⚠️ | works with a caution |
| 🟢 | high or good on one property |
| 🟡 | medium on that property |
| 🔴 | low or bad on that property |

## 10. Left out on purpose

- Skin-tone, gendered, and joined sequences (two emoji glued into one), which
  split into two glyphs on older systems.
- Flags, keycap digits, and anything from Emoji 12 or later, which shows as an
  empty box on many terminals and older Windows builds.
- Coloured circles and squares beyond the status six, so a colour never means
  two things in one answer.
- Faces and hearts, which add tone rather than navigation.
